2) Required software
=====================================================================
Windows:
- Git
- Python 3.13+ (recommended: 3.13.x)
- Node.js 18+ (LTS)
- ffmpeg in PATH
- (optional but recommended) PowerShell 7

macOS:
- Git
- Python 3.13+ (or 3.x where project dependencies are supported)
- Node.js 18+ (LTS)
- ffmpeg
- (recommended) Homebrew

Runtime Python packages installed by backend requirements include adapters such as:
- vosk
- faster-whisper
- sherpa-onnx (as configured in backend requirements / your venv)
- qwen-asr toolchain components when used

=====================================================================
3) Install whole app (Windows)
=====================================================================
From repository root:

1) Clone:
   git clone https://github.com/Misak89/aSTT-comp.git
   cd aSTT-comp

2) Create venv + backend deps:
   py -3.13 -m venv .venv
   .venv\Scripts\pip install -r backend/requirements.txt

3) Frontend deps + build:
   npm --prefix frontend install
   npm --prefix frontend run build

4) Start app:
   web-up.cmd
   (or web-up-build.cmd for build+start)

5) Open:
   http://127.0.0.1:8012

=====================================================================
5) Recommended install scripts
=====================================================================
Interactive scripts included in repo:
- Windows: scripts/install_astt_windows.ps1
- macOS:  scripts/install_astt_macos.sh

What scripts do:
- check prerequisites
- create venv and install dependencies (optional prompts)
- install/build frontend (optional prompts)
- install whisper runtime (whisper-cli + whisper-server)
- for each core whisper model: show approx download size, ask Download/Skip
- optional installs for VOSK and selected HuggingFace models

Run scripts:
- Windows:
  powershell -ExecutionPolicy Bypass -File scripts/install_astt_windows.ps1

- macOS:
  chmod +x scripts/install_astt_macos.sh
  ./scripts/install_astt_macos.sh

=====================================================================
6) Core STT model install (required minimum)
=====================================================================
Core minimum requested by project:
- whisper.cpp base
- whisper.cpp small
- whisper.cpp large-v3
- whisper.cpp large-v3-turbo

Important:
- whisper.cpp requires runtime binary (whisper-cli; for mic also whisper-server).
- In this project, runtime/model layout is expected under:
  runtime/model_store/<model_id>/

Core files expected by app:
- runtime/model_store/whisper_cpp_base/ggml-base.bin
- runtime/model_store/whisper_cpp_small/ggml-small.bin
- runtime/model_store/whisper_cpp_large_v3/ggml-large-v3-q5_0.bin (or compatible large-v3 file)
- runtime/model_store/whisper_cpp_large_v3_turbo/ggml-large-v3-turbo-q5_0.bin

=====================================================================
7) Optional models (how to install)
=====================================================================
1) sherpa-onnx small:
- place a complete transducer bundle to runtime/model_store/sherpa_onnx_small
- bundle must include tokens + encoder/decoder/joiner ONNX files

2) VOSK small cs-0.4:
- unzip model folder to runtime/model_store/vosk_small_cs_0_4
- required files include conf/model.conf and acoustic model files

3) faster-whisper small/medium (CZ int8):
- place CTranslate2 model in:
  - runtime/model_store/faster_whisper_small_cs_int8/
  - runtime/model_store/faster_whisper_medium_cs_int8/
- expected file: model.bin (+ tokenizer/config files)

4) Qwen3-ASR 0.6B:
- place HF snapshot in runtime/model_store/qwen3_asr_0_6b/
- required files include config/tokenizer/preprocessor + model weights

10) Troubleshooting
=====================================================================
- "Model missing":
  Check exact expected file names and directories in section 6 and 7.

- "whisper runtime missing":
  Install/copy whisper-cli (and preferably whisper-server) into:
  runtime/model_store/whisper_cpp/

- "ffmpeg missing":
  Install ffmpeg and verify command:
  ffmpeg -version

- "frontend changes not visible":
  Rebuild frontend:
  npm --prefix frontend run build

- "Python package missing":
  Reinstall backend dependencies in venv:
  .venv\Scripts\pip install -r backend/requirements.txt
  or
  .venv/bin/pip install -r backend/requirements.txt
